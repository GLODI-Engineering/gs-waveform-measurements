## 2026-11-19 01:17 — the README says who depends on this crate

[#5](https://github.com/GLODI-Engineering/gs-waveform-measurements/issues/5). The one section a
reader consults to find out whether anything uses this library — "History" — said the crate was
between users: *"once a consumer in a sibling repository needs it again"*, and anticipated
*"switching to a published `version` once this crate has one"*. Both had already happened:
0.1.0 is on crates.io, the engine evaluates `kind=measure` with these primitives, and
`gsim_tools.measure` is a Python port cross-validated against this crate measurement by
measurement.

- A "Who depends on this" section names both consumers and why the crate is published rather
  than vendored. The path-dependency convention stays, with the `version` beside it.
- Badges and `gs-waveform-measurements = "0.1"` at the top. There was no install instruction
  anywhere in the file; the only dependency snippet was the path line inside "History".
- The API guidance was one sentence pointing at `cargo doc`. There is now a six-row module table
  and a worked example for each of the three functions that are easiest to use incorrectly:
  `trig_targ`, `four` and `error_norm`.
- Those three examples are compiled and checked in `tests/readme_examples.rs`, which also puts
  the `tests/` directory — present, empty and untracked until now — to use. The expected values
  are derived by hand, per this project's verification discipline, not recorded from a run:
  650 ns between two interpolated fractions of a step's own peak; a unit triangle's harmonics
  $A_n = 8/(\pi^2 n^2)$ for odd $n$, zero for even $n$, and THD exactly $100/9\%$ with the
  third harmonic as the only overtone inside the bound; $\sqrt{0.25/3}$ for the L2 norm. All
  three passed on the first run, which is also the strongest evidence yet that the closed-form
  segment integral in `fourier` is exact rather than merely close.
- `src/lib.rs`'s own crate documentation — the text docs.rs renders — still described this crate
  as living inside a workspace, with "anything else in this repository" meaning the engine's
  crates. Rewritten to name the workspace it was extracted from.
- `homepage` repeated `repository` verbatim, which `cargo::redundant_homepage` warns about on
  every build.

Verification: `cargo fmt --all -- --check`, `cargo clippy --all-targets -- -D warnings` (now
silent, manifest included), `cargo test --all-targets` (29 inline + 3 README examples) and
`cargo doc --no-deps --lib`.

Remaining: the crate still has very few commits and `docs/gotchas/INDEX.md` is still empty. Both
are true facts about a small, finished library rather than defects to fix.
