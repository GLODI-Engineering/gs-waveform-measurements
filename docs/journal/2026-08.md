## 2026-08-29 00:18 — Extracted from `general-simulator` into its own repository

`gs-waveform-measurements` was originally built earlier in the `general-simulator` workspace as
a standalone crate (empty `[dependencies]`, no dependency on `general-simulator`'s own circuit or
block-diagram types) but was never committed there — it existed only as an untracked directory
plus an uncommitted one-line addition to that workspace's `Cargo.toml` `members` list. It is
extracted here, as this repository's own root crate (not nested under a `crates/` directory —
this is a single-crate repo, matching `general-mna`'s own layout), rather than committed into
`general-simulator`'s history, for two reasons: it can carry its own release cadence independent
of `general-simulator`'s, and it is meant to be reusable beyond that one simulator project — it
takes only `Sample` slices as input and has no notion of a circuit, block graph, or netlist.

`src/`, `tests/`, and `Cargo.toml` moved unchanged (a pure file move — no behavior change); only
`Cargo.toml`'s workspace-inherited fields (`edition`, `license`, `publish`, `repository`,
`homepage`) were replaced with the concrete values `general-simulator`'s own
`[workspace.package]` inherited from, since there is no workspace here. Repository bootstrap
(`LICENSE`, `.gitignore`, `README.md`, `AGENTS.md`/`CLAUDE.md`, this journal, `docs/gotchas/`,
`.pre-commit-config.yaml`, `scripts/style-guard.sh`) follows `general-mna`'s own established
template for a sibling repo in this project family (see that repo's own
`docs/journal/2026-08.md`, 2026-08-01 19:21 entry, "Adopt reusable repository workflow").

This crate is **not** wired into `general-simulator` (or any other repository) as a dependency
yet — no consumer currently depends on it. That integration (most likely `dae-runtime` or
`general-simulator-cli` reading `.measure`/`.MEASURE`-style netlist statements and calling into
this crate's primitives) is separate, later work. When it happens, the convention documented in
this repository's own `README.md` and `general-mna`'s own README is to add it back as a
sibling-path dependency during development
(`gs-waveform-measurements = { path = "../gs-waveform-measurements" }`), switching to a
published `version` once one exists.

For the crate's original design rationale and its non-uniform-timestep verification strategy
(why every measurement is Δt-weighted or exactly-integrated rather than resampled to a uniform
grid, and how each was checked against hand-derived expected values), see `general-simulator`'s
own `docs/journal/` and this crate's own `src/lib.rs` crate-level doc comment — not duplicated
here.

Verification (from this new repository, a genuine standalone build, not assumed from the prior
location): `cargo build`, `cargo test --all-targets`, `cargo fmt --all -- --check`,
`cargo clippy --all-targets -- -D warnings`, and `cargo doc --no-deps --lib` (the crate keeps
`#![warn(missing_docs)]`) all clean. The README's own usage example was run as a throwaway
`cargo run --example` scratch file before being written down, then removed.
